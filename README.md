# colmeia-site
Imagens e conteúdo sobre como as cores influenciam emoções, percepções e comportamento.
O Colméia é um site dedicado a reunir imagens e conteúdos educativos sobre psicologia das cores 
Explorando como diferentes tonalidades influenciam emoções, comportamentos, decisões e percepções das pessoas, e por que esse conhecimento é importante em áreas como design, marketing, ambientes e bem-estar.
